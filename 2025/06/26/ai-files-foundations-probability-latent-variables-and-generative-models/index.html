基础知识：概率与潜变量模型：生成模型到底在学什么

生成模型不是把训练样本背下来，也不是“随机画一个像样的东西”。它要学的是一个分布：哪些样本可能出现，哪些条件会改变样本，哪些隐藏因素可以解释观测到的数据。VAE、扩散模型、RSSM / Dreamer、JEPA、视频世界模型都会反复使用这套语言。

当论文写 pθ(x)p_\theta(x)pθ​(x)、pθ(x∣z)p_\theta(x\mid z)pθ​(x∣z)、qϕ(z∣x)q_\phi(z\mid x)qϕ​(z∣x)、ELBO、score 和 latent state 时，需要判断它们分别在训练链条里扮演什么角色。

数学先修

需要用到概率、条件分布与贝叶斯、熵与 KL，并把它们接到潜变量、ELBO、energy 与 score。

分布不是标签，而是可能性的形状

如果真实数据来自未知分布，可以写成：

x∼pdata(x)x \sim p_{\text{data}}(x) x∼pdata​(x)

模型要学一个 pθ(x)p_\theta(x)pθ​(x) 去接近它。这里 xxx 可以是一张图、一段视频、一串 token、一个机器人轨迹，也可以是世界模型里的未来状态。条件生成则多一个条件：

pθ(x∣c)p_\theta(x\mid c) pθ​(x∣c)

ccc 可以是文本、类别、图像、动作、目标状态或历史观测。这个式子的含义不是“模型确定地产生一个 xxx”，而是“在条件 ccc 下，哪些 xxx 更可能”。同一个 prompt 可以有多张合理图，同一个当前状态也可能有多种未来，所以生成模型必须处理多种可能性。

训练时常见的 maximum likelihood 是：

max⁡θ∑ilog⁡pθ(xi)\max_\theta \sum_i \log p_\theta(x_i) θmax​i∑​logpθ​(xi​)

直觉很简单：真实样本 xix_ixi​ 在模型分布下概率越高，loss 越小。但很多强生成模型不会直接显式写出完整 pθ(x)p_\theta(x)pθ​(x)，而是借助 latent variable、denoising objective、score matching 或 autoregressive factorization 来训练。

生成模型最容易被一个名字遮住差异。更稳的办法是先看它提供什么概率接口：

建模接口 主要训练信号 能否直接得到规范化密度 推理 / 采样方式
Autoregressive likelihood next-token / next-step NLL 能，靠条件概率连乘 按顺序逐步采样
Latent-variable likelihood ELBO、reconstruction、KL 边际 likelihood 常需近似 从 prior 采 zzz，再由 decoder 生成
Energy-based compatibility 正负样本能量差或正则化 energy partition function 常不可算 优化或采样寻找低能量状态
Implicit generator adversarial / distribution matching 通常不能 噪声一次或少步映射到样本
Score / diffusion model denoising、score matching 不是常用训练接口 沿 SDE、ODE 或离散 sampler 迭代

这张表不是在选唯一赢家。Autoregressive 模型密度清楚但采样串行；VAE 有结构化 latent 但优化下界；EBM 表达兼容性灵活但归一化和搜索困难；implicit model 采样快却没有显式 likelihood；扩散生成质量强但推理要积分或多步更新。数学定义和边界见潜变量、似然与生成模型目标。

潜变量：把看不见的因素放进模型

很多观测背后都有隐藏因素。人脸图像背后有身份、姿态、光照、表情；机器人观测背后有速度、接触状态、遮挡物；视频世界模型背后有还没被直接看到的动力学状态。潜变量 zzz 就是模型用来表示这些隐藏因素的随机变量。

一个最小 latent-variable generative model 可以写成：

z∼p(z),x∼pθ(x∣z)z \sim p(z), \qquad x \sim p_\theta(x\mid z) z∼p(z),x∼pθ​(x∣z)

合起来得到边际分布：

pθ(x)=∫pθ(x∣z)p(z) dzp_\theta(x)=\int p_\theta(x\mid z)p(z)\,dz pθ​(x)=∫pθ​(x∣z)p(z)dz

这行公式在说：要生成 xxx，模型先从先验 p(z)p(z)p(z) 里抽一个内部原因，再通过 decoder / generative model 生成观测。这里的 pθ(x∣z)p_\theta(x\mid z)pθ​(x∣z) 通常不是一个普通确定性函数，而是一个由神经网络参数化的概率分布；网络可能输出均值、方差、logits 或其他分布参数。

推断方向：看到 xxx 后反推 zzz

生成方向是 z→xz\rightarrow xz→x。训练时我们看到的是 xxx，经常需要反过来问：这个样本可能由哪些 zzz 产生？这叫 posterior inference：

pθ(z∣x)=pθ(x∣z)p(z)pθ(x)p_\theta(z\mid x)=\frac{p_\theta(x\mid z)p(z)}{p_\theta(x)} pθ​(z∣x)=pθ​(x)pθ​(x∣z)p(z)​

难点正好在分母：

pθ(x)=∫pθ(x∣z)p(z) dzp_\theta(x)=\int p_\theta(x\mid z)p(z)\,dz pθ​(x)=∫pθ​(x∣z)p(z)dz

对高维连续 latent 和神经网络 decoder，这个积分通常不可算。VAE 的解决办法不是“硬算后验”，而是训练一个 inference model：

qϕ(z∣x)q_\phi(z\mid x) qϕ​(z∣x)

它用简单可采样的分布去近似真实 posterior pθ(z∣x)p_\theta(z\mid x)pθ​(z∣x)。因此，VAE 里的 encoder 更准确地说是 recognition / inference model；decoder 才是生成模型的一部分。

ELBO：把不可算 likelihood 换成可优化下界

从任意近似分布 qϕ(z∣x)q_\phi(z\mid x)qϕ​(z∣x) 出发，可以把真实 likelihood 拆成：

log⁡pθ(x)=Eqϕ(z∣x)[log⁡pθ(x,z)−log⁡qϕ(z∣x)]⏟LELBO(x)+KL(qϕ(z∣x) ∥ pθ(z∣x))⏟≥0\log p_\theta(x) = \underbrace{ \mathbb{E}_{q_\phi(z\mid x)} \left[ \log p_\theta(x,z)-\log q_\phi(z\mid x) \right] }_{\mathcal{L}_{\text{ELBO}}(x)} + \underbrace{ \mathrm{KL}\left(q_\phi(z\mid x)\,\|\,p_\theta(z\mid x)\right) }_{\ge 0} logpθ​(x)=LELBO​(x)Eqϕ​(z∣x)​[logpθ​(x,z)−logqϕ​(z∣x)]​​+≥0KL(qϕ​(z∣x)∥pθ​(z∣x))​​

因为 KL divergence 非负，LELBO\mathcal{L}_{\text{ELBO}}LELBO​ 就是 log⁡pθ(x)\log p_\theta(x)logpθ​(x) 的下界。最大化 ELBO 有两个效果：一边把下界往上推，让模型更能解释数据；一边让 qϕ(z∣x)q_\phi(z\mid x)qϕ​(z∣x) 更靠近真实 posterior。

把联合分布 pθ(x,z)=pθ(x∣z)p(z)p_\theta(x,z)=p_\theta(x\mid z)p(z)pθ​(x,z)=pθ​(x∣z)p(z) 展开，常见 VAE 形式是：

LELBO(x)=Eqϕ(z∣x)[log⁡pθ(x∣z)]−KL(qϕ(z∣x) ∥ p(z))\mathcal{L}_{\text{ELBO}}(x) = \mathbb{E}_{q_\phi(z\mid x)}[\log p_\theta(x\mid z)] - \mathrm{KL}\left(q_\phi(z\mid x)\,\|\,p(z)\right) LELBO​(x)=Eqϕ​(z∣x)​[logpθ​(x∣z)]−KL(qϕ​(z∣x)∥p(z))

第一项常被叫 reconstruction term，但它不是普通像素 MSE 的同义词；它是在问“从这个 latent 生成真实样本的概率有多高”。第二项把每个样本的 posterior 拉回统一先验 p(z)p(z)p(z)，否则 encoder 可能给每个训练样本分配一块互不相干的 latent 空间，采样时从 p(z)p(z)p(z) 抽出来的点就很难被 decoder 正确使用。

重参数化：让采样也能反向传播

VAE pipeline 里，encoder 不只要输出 posterior 参数，还要从 posterior 取一个 zzz 交给 decoder。直接的采样节点会挡住 encoder 梯度，所以高斯 posterior 常写成：

qϕ(z∣x)=N(μϕ(x),diag(σϕ2(x)))q_\phi(z\mid x)=\mathcal{N}(\mu_\phi(x),\mathrm{diag}(\sigma_\phi^2(x))) qϕ​(z∣x)=N(μϕ​(x),diag(σϕ2​(x)))

ϵ∼N(0,I),z=μϕ(x)+σϕ(x)⊙ϵ\epsilon\sim\mathcal{N}(0,I), \qquad z=\mu_\phi(x)+\sigma_\phi(x)\odot \epsilon ϵ∼N(0,I),z=μϕ​(x)+σϕ​(x)⊙ϵ

这样 forward 仍从同一个 posterior 得到随机 zzz，backward 却可以沿 μϕ(x)\mu_\phi(x)μϕ​(x) 和 σϕ(x)\sigma_\phi(x)σϕ​(x) 回到 encoder。它在生成模型 pipeline 中负责连接“近似 posterior”和“可训练 decoder”；为什么这种改写能给出 pathwise gradient，以及离散 latent 为什么常改用 STE，放在梯度估计、离散变量与训练信号中展开。

KL 项不是装饰：太强太弱都会出问题

ELBO 里的 KL 项常被初学者当作“正则化”，但它实际控制的是 posterior 和 prior 的关系。KL 太弱时，encoder 可能把样本记到分散的 latent 角落，重建很好，但从 prior 采样会生成差。KL 太强时，qϕ(z∣x)q_\phi(z\mid x)qϕ​(z∣x) 被迫过于接近 p(z)p(z)p(z)，decoder 可能学会忽略 zzz，这就是常说的 posterior collapse 风险之一。

所以 VAE 不是“autoencoder 加噪声”。它是在三件事之间折中：latent 要解释当前样本，latent 要能从统一先验中采样，decoder 要能把 latent 变成观测分布。

扩散模型：不用显式密度，也能学分布方向

扩散模型也在学习分布，但方式不同。它先定义一个正向加噪过程 q(xt∣xt−1)q(x_t\mid x_{t-1})q(xt​∣xt−1​)，把真实样本逐步推向噪声；再训练反向模型 pθ(xt−1∣xt)p_\theta(x_{t-1}\mid x_t)pθ​(xt−1​∣xt​)，从噪声一步步回到数据。

图源：Denoising Diffusion Probabilistic Models，Figure 2。原图表达前向过程 q(xt∣xt−1)q(x_t\mid x_{t-1})q(xt​∣xt−1​) 逐步加噪，反向过程 pθ(xt−1∣xt)p_\theta(x_{t-1}\mid x_t)pθ​(xt−1​∣xt​) 逐步去噪。读图重点是把 xtx_txt​ 看成一串受控噪声状态：训练目标不是直接写出 p(x)p(x)p(x)，而是在每个噪声水平学习回到数据分布的局部方向。

Score 是另一种描述分布的方式：

∇xlog⁡p(x)\nabla_x \log p(x) ∇x​logp(x)

它表示当前位置往哪个方向移动会让 log density 上升。扩散训练里的噪声预测和 score 有尺度关系；模型看起来在做 MSE 去噪，本质上是在不同噪声水平学习一个概率方向场。

图源：Score-Based Generative Modeling through Stochastic Differential Equations，Figure 1。原图表达正向 SDE 把数据扰动到噪声，反向 SDE 依赖每个中间分布的 score 生成样本。读图重点是把 score 当作“分布地形上的坡度”：生成不是一次性解码，而是沿着学到的方向场积分回数据区域。

世界模型里的 latent：状态要服务预测和决策

在 VAE 中，latent 常常服务重建和采样；在扩散中，xtx_txt​ 是噪声链上的中间状态；在世界模型里，latent 更接近 agent 的 belief state。它要压缩历史观测和动作，还要保留未来预测、奖励、风险和规划需要的信息。

图源：Learning Latent Dynamics for Planning from Pixels，Figure 2。原图比较 RNN、SSM 和 RSSM 三种 latent dynamics 设计。读图重点是看 deterministic memory 和 stochastic state 的分工：前者记历史，后者表达不确定未来，二者合在一起才能服务 planning。

这也是为什么“latent”不能被翻译成一个固定概念就结束。读论文时要追问：这个 latent 来自哪里？它是从 prior 采样、从 posterior 推断、从 denoising chain 递推，还是从历史观测更新？它最后服务的是生成图像、压缩 token、预测未来，还是选择动作？

不确定性会在 rollout 里放大

概率语言对世界模型特别重要，因为决策系统害怕长尾错误。假设 risk head 对“接触即将失败”的单步漏报率是 5%。看单步不大，但 20 步 rollout 中至少漏一次的概率是：

1−(1−0.05)20≈64.2%1-(1-0.05)^{20}\approx 64.2\% 1−(1−0.05)20≈64.2%

这说明多步预测不能只报最可能未来。若未来分布是多峰的，均值预测可能 loss 低，却把“会滑落”和“能抓稳”平均成不存在的中间状态。对 planner 来说，中间状态不是安全折中，而是错误世界模型给出的虚假可行动作。

读生成模型时先问四个问题

第一，模型定义的随机变量是什么：是 xxx、zzz、xtx_txt​、belief state，还是动作序列？第二，模型提供的是规范化 likelihood、下界、energy、implicit samples，还是 score？第三，采样或推理时从哪里开始：prior、噪声、posterior state，还是真实历史观测？第四，评测看什么：likelihood、sample quality、prompt alignment、calibration、closed-loop success，还是 planner 的候选排序？

这些问题能避免几个常见误解：likelihood 高不等于样本好看；重建好不等于 latent 可采样；视频预测清晰不等于能规划；score 准也不等于少步采样一定稳定；latent 省 token 不等于保留了行动相关状态。

读完以后怎么判断

概率与潜变量模型的核心不是背公式，而是分清三条链。生成链：z∼p(z)z\sim p(z)z∼p(z)，再从 pθ(x∣z)p_\theta(x\mid z)pθ​(x∣z) 生成观测。推断链：看到 xxx 后用 qϕ(z∣x)q_\phi(z\mid x)qϕ​(z∣x) 近似不可算 posterior。采样链：从 prior、噪声或 posterior state 出发，用训练好的模型逐步生成样本或未来状态。

VAE 用 ELBO 把不可算的边际似然变成可优化下界；扩散用受控加噪把分布学习变成方向场学习；世界模型用 latent state 把历史、不确定性和动作后果压到可 rollout 的状态空间。把这三条链看清，后面的扩散、Dreamer、V-JEPA、VLA 和视频世界模型公式就不再只是符号。
