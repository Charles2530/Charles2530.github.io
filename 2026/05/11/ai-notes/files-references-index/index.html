1. 扩散模型与生成模型

对应站内章节：扩散模型。

1.1 必读起点

  1. Denoising Diffusion Probabilistic Models
    DDPM 的经典起点，建立“逐步加噪、逐步去噪”的基本框架。
  2. Denoising Diffusion Implicit Models
    DDIM 解释为什么采样路径可以非马尔可夫化，是少步采样和确定性采样的重要基础。
  3. Score-Based Generative Modeling through Stochastic Differential Equations
    把扩散过程放到 SDE / ODE 视角，是理解连续时间扩散、概率流 ODE 和求解器的关键论文。
  4. Elucidating the Design Space of Diffusion-Based Generative Models
    EDM 把噪声参数化、采样器、预条件等设计拆开，是工程调参和复现实验很值得反复看的论文。

1.2 快速采样、求解器与少步蒸馏

  1. DPM-Solver: A Fast ODE Solver for Diffusion Probabilistic Model Sampling in Around 10 Steps
    从数值积分角度设计扩散采样器，适合连接站内“求解器视角”内容。
  2. DPM-Solver++: Fast Solver for Guided Sampling of Diffusion Probabilistic Models
    更贴近 classifier-free guidance 等实际生成配置。
  3. Progressive Distillation for Fast Sampling of Diffusion Models
    少步蒸馏的经典路线：把多步 teacher 压成少步 student；也常作为理解 (v)-prediction / velocity 参数化的入口之一。
  4. Consistency Models
    把不同噪声水平映射到同一数据点，适合理解一步/少步生成的另一条路线。
  5. Latent Consistency Models
    LCM 是把 consistency 思路推向 Stable Diffusion 生态的实用论文。
  6. Improved Distribution Matching Distillation for Fast Image Synthesis
    DMD2 值得放在少步蒸馏里看，关注分布匹配和高质量少步生成。

1.3 Rectified Flow、Rectified Diffusion 与视频扩散

  1. Flow Straight and Fast: Learning to Generate and Transfer Data with Rectified Flow
    Rectified Flow 关注把生成路径“拉直”，降低求解难度。
  2. Flow Matching for Generative Modeling
    Flow Matching 直接拟合连续生成路径上的速度场，是理解 velocity、ODE 采样和现代 flow-style 视频生成的重要论文。
  3. InstaFlow: One Step is Enough for High-Quality Diffusion-Based Text-to-Image Generation
    少步/一步生成与 rectified flow 结合的重要实例。
  4. Rectified Diffusion: Straightness Is Not Your Need in Rectified Flow
    适合补充 Rectified Diffusion 术语：重点不是简单追求路径直，而是重新分析整流目标、采样效率与生成质量之间的关系。
  5. Video Diffusion Models
    视频扩散的早期代表，适合作为时序生成入口。
  6. Imagen Video: High Definition Video Generation with Diffusion Models
    多级级联视频生成路线，对理解高分辨率视频生成系统很有帮助。
  7. Wan: Open and Advanced Large-Scale Video Generative Models
    Wan2.1 技术报告，适合理解开源视频 foundation model 的 VAE、DiT、Flow Matching、多任务和系统训练设计；站内专题见 Wan2.1 深度讲解。
  8. Wan2.1 官方 GitHub
    开源模型、推理脚本和任务接口入口，覆盖 T2V、I2V、editing、T2I 和 V2A 等任务。
  9. Wan2.2 官方 GitHub
    Wan2.2 的 MoE、高低噪声专家、A14B、TI2V-5B、Animate 和 S2V 等模型入口，适合连接视频扩散与世界模型专题。

2.1 视觉语言预训练与时序表征

  2. Flamingo: a Visual Language Model for Few-Shot Learning

4. 世界模型、训练与规划

对应站内章节：世界模型。

4.1 必读起点：latent dynamics 与 imagined rollout

    把“压缩观测、学习动态、在想象中规划”讲清楚的经典起点。
  2. Learning Latent Dynamics for Planning from Pixels

  3. Dream to Control: Learning Behaviors by Latent Imagination

  4. Mastering Atari with Discrete World Models

  5. Mastering Diverse Domains through World Models

  4. Masked World Models for Visual Control

  4. Genie: Generative Interactive Environments

  5. Video Language Planning
    连接视频预测、语言规划和长程任务分解。
  6. Genie 3 官方页面
    官方 demo 适合观察实时探索、长时环境一致性和文本到可交互世界的系统形态。
  7. NVIDIA Cosmos 官方页面

  8. LingBot-World 官方 GitHub

  5. nuScenes

4.5 世界模型 Benchmark 与开放难题

    用于测试泛化和分布外表现，适合检验 world model 是否只是记住训练环境。
  2. VBench: Comprehensive Benchmark Suite for Video Generative Models

4.6 世界模型训练效率与系统优化

这里的参考文献只收“让训练更高效”的工作，不把普通 world model 训练目标、loss 设计或模型谱系重复列入。阅读时重点看它们优化的是哪一种效率：真实交互步数、训练 wall-clock、显存/序列计算、rollout 复用率，还是把视频基础模型低成本改造成可交互模拟器。

样本效率：更少真实环境交互

  1. Model-Based Reinforcement Learning for Atari
    SimPLe 是早期代表：用视频预测模型生成短期模拟轨迹，让 policy 在 learned model 里训练，从而减少 Atari 真实交互量。
  2. Mastering Atari Games with Limited Data
    EfficientZero 重点是有限数据下的 sample-efficient RL，把 learned model、self-supervised consistency、value prefix 和 MCTS 结合起来。
  3. EfficientZero V2: Mastering Discrete and Continuous Control with Limited Data
    把 EfficientZero 推到离散/连续动作、视觉/低维输入的统一框架，适合看有限数据设置下 world model + planning 的通用化。

Transformer world model：并行训练与 token 效率

  1. Transformers are Sample-Efficient World Models
    IRIS 用离散 autoencoder 把像素压成 tokens，再用 autoregressive Transformer 建模动态，是 tokenized world model 的重要入口。
  2. Transformer-based World Models Are Happy With 100k Interactions
    TWM 关注 Transformer world model 在 Atari 100k 低数据场景下的训练效率，适合和 IRIS、STORM 对比。
  3. STORM: Efficient Stochastic Transformer based World Models for Reinforcement Learning
    把 stochastic latent 和 Transformer 序列建模结合，论文直接报告了单卡训练时间，是 wall-clock 维度很值得看的工作。
  4. Efficient World Models with Context-Aware Tokenization
    Delta-IRIS / Δ-IRIS 重点在 tokenization：减少不必要 token 和长序列计算，是“世界模型训练效率”里很直接的一类优化。
  5. Learning Transformer-based World Models with Contrastive Predictive Coding
    TWISTER 用 action-conditioned CPC 改善 Transformer world model 表征学习，重点看表示质量和样本效率的关系。

连续控制：可扩展模型与数据复用

  1. TD-MPC2: Scalable, Robust World Models for Continuous Control
    TD-MPC2 关注 decoder-free latent world model、TD learning 与 MPC 的结合，重点看多任务数据、模型规模和固定超参如何提升训练可扩展性。

长上下文训练：降低序列长度带来的系统成本

  1. World Model on Million-Length Video And Language With Blockwise RingAttention
    LWM 用 Blockwise RingAttention 处理百万级 video-language token，是长视频世界模型训练系统的直接参考。
  2. Long-Context State-Space Video World Models
    用 state-space memory 处理长时依赖，并结合 local attention 保留局部视觉细节，重点是让长时 rollout 成本不要随历史长度线性失控。

视频世界模型实时化：从离线生成训练到 streaming rollout

  1. Diffusion Forcing: Next-token Prediction Meets Full-Sequence Diffusion
    用每帧独立噪声水平把 full-sequence diffusion 和 next-token prediction 接起来，适合看视频模型如何获得更自然的 causal rollout 训练形式。
  2. From Slow Bidirectional to Fast Autoregressive Video Diffusion Models
    CausVid 把预训练 bidirectional video diffusion 改造成 causal autoregressive video diffusion，并通过 distillation 和 KV cache 降低交互延迟。
  3. MAGI-1: Autoregressive Video Generation at Scale
    从 chunk-wise autoregressive video generation 出发讨论大规模训练和部署基础设施，重点看 causal video foundation model 如何保持固定峰值推理成本。
  4. Self Forcing: Bridging the Train-Test Gap in Autoregressive Video Diffusion
    把 inference-time autoregressive rollout 的状态分布带进训练，重点解决 teacher forcing 和自回归推理之间的分布错位。
  5. Autoregressive Adversarial Post-Training for Real-Time Interactive Video Generation
    AAPT 关注少步、实时、交互式视频生成的 post-training，是把视频生成模型推向交互世界模拟器的重要效率方向。

为什么世界模型文献要单独强调训练与评测

世界模型的核心难点不只是“能不能生成未来帧”，而是生成的 latent 是否能支持下游规划、控制、反事实推理和泛化。重建 loss、next-frame prediction loss、FID 或视频视觉质量指标都只能回答一部分问题。更有价值的 benchmark 应该把下游任务泛化、rollout 误差累积、规划质量和交互控制成功率放到核心位置。

5. 强化学习、后训练与世界模型

对应站内章节：强化学习。

5.1 强化学习基础方法

  1. DeepSeek-R1: Incentivizing Reasoning Capability in LLMs via Reinforcement Learning
    用 GRPO、rule-based reward 和大规模 RLVR 训练长 CoT reasoning model 的关键技术报告；站内专题见 DeepSeek-R1 讲解。

  2. Qwen3 Technical Report
    Qwen3 把 thinking / non-thinking 双模式、thinking budget、GRPO、general RL 和 strong-to-weak distillation 合到同一个开源模型家族；站内专题见 Qwen3 讲解。

  3. Gemini 2.5: Pushing the Frontier with Advanced Reasoning, Multimodality, Long Context, and Next Generation Agentic Capabilities
    Gemini 2.5 把 native multimodal sparse MoE、teacher distillation、TPUv5p/Pathways、SFT/RM/RL、dynamic thinking、长上下文和 agentic / multimodal 后训练合到同一条闭源前沿模型路线；站内专题见 Gemini 2.5 讲解。

  4. Kimi K2: Open Agentic Intelligence
    Kimi K2 用 MuonClip 跑稳 1T MoE 预训练，并把 agentic data synthesis、tool-use SFT、RLVR、self-critique reward 和 RL rollout 基础设施合成一条开放 agent 模型路线；站内专题见 Kimi K2 讲解。

  5. Qwen3.5-Omni Technical Report
    Qwen3.5-Omni 用 Thinker-Talker、Hybrid MoE、AuT、ARIA、RVQ/MTP/Code2Wav 和 256K context 构建可流式语音交互的全模态 agent；站内专题见 Qwen3.5-Omni 讲解。

  6. Playing Atari with Deep Reinforcement Learning
    DQN 是深度强化学习的经典起点，适合理解 value learning、replay buffer 和 target network。

  7. Asynchronous Methods for Deep Reinforcement Learning
    A3C 适合理解并行 actor、异步采样、entropy regularization 和现代 RL 系统中 rollout worker 的来源。

  8. High-Dimensional Continuous Control Using Generalized Advantage Estimation
    GAE 是 PPO/actor-critic 中常见的 advantage 估计方法，重点看 bias-variance tradeoff。

  9. Proximal Policy Optimization Algorithms
    PPO 是现代 RLHF 和很多 actor-critic 训练栈的核心算法入口。

  10. Soft Actor-Critic: Off-Policy Maximum Entropy Deep Reinforcement Learning with a Stochastic Actor
    SAC 适合理解 off-policy actor-critic、maximum entropy objective、reward scale 和探索稳定性。

  11. Offline Reinforcement Learning: Tutorial, Review, and Perspectives on Open Problems
    Offline RL 适合理解固定数据集训练、behavior policy、support constraint、trajectory stitching 和机器人数据复用。

  12. Decision Transformer: Reinforcement Learning via Sequence Modeling
    Decision Transformer 适合理解 return-conditioned trajectory modeling，以及为什么 VLA / 世界模型可以把状态、动作和回报组织成 Transformer 序列。

  13. DeepSeekMath: Pushing the Limits of Mathematical Reasoning in Open Language Models
    GRPO 的重要来源之一，适合理解组内相对奖励如何减少 critic 依赖。

5.2 LLM/VLM 后训练与 verl

  1. Training language models to follow instructions with human feedback
    InstructGPT 是 SFT、reward model 和 PPO/RLHF 三步流程的基础论文。
  2. HybridFlow: A Flexible and Efficient RLHF Framework
    HybridFlow / verl 适合理解大模型 RLHF 为什么需要 dataflow、worker、rollout backend 和资源映射。
  3. A Framework for Training Large Language Models for Code Generation via Proximal Policy Optimization
    适合从代码生成任务看 PPO 后训练的数据、奖励和系统约束。

5.3 强化学习与世界模型

  1. Learning Latent Dynamics for Planning from Pixels
    PlaNet 是从像素学习 RSSM latent dynamics 并做 latent-space planning 的关键论文。
  2. Dream to Control: Learning Behaviors by Latent Imagination
    Dreamer 把 world model 变成 imagined actor-critic 的训练环境。
  3. Mastering Diverse Domains through World Models
    DreamerV3 适合理解跨任务鲁棒 world model RL 的稳定化设计。
  4. TD-MPC2: Scalable, Robust World Models for Continuous Control
    TD-MPC2 连接 decoder-free latent world model、TD learning 和 MPC。
  5. RLVR-World: Training World Models with Reinforcement Learning
    RLVR-World 展示如何用可验证奖励直接优化语言和视频世界模型的任务指标。

6. 量化、数制与低比特训练

对应站内章节：量化。

6.1 低比特 LLM 综述与基础数制

  1. A Survey of Low-bit Large Language Models: Basics, Systems, and Algorithms
    推荐作为量化专题的总入口：把数值格式、算法、系统和训练路线放在同一张地图里。
  2. FP8 Formats for Deep Learning
    E4M3 / E5M2 的基础论文，适合理解 FP8 为什么比 INT8 更自然地适配训练和推理。
  3. Microscaling Data Formats for Deep Learning
    MXFP / MXINT 微缩放格式入口，是 MXFP8 / MXFP4 的基础。
  4. Ascend HiFloat8 Format for Deep Learning
    HiFloat8 / HIFP8 方向入口，适合和 FP8、MXFP8 对比动态范围和尾数分配。
  5. OCP Microscaling Formats MX v1.0 Specification
    MX 格式标准参考。

6.2 PTQ、权重量化与激活离群值

  1. LLM.int8(): 8-bit Matrix Multiplication for Transformers at Scale
    解释大模型 activation outlier 为什么会破坏朴素 INT8。
  2. GPTQ: Accurate Post-Training Quantization for Generative Pre-trained Transformers
    权重量化经典方法，适合理解二阶信息和逐列量化。
  3. SmoothQuant: Accurate and Efficient Post-Training Quantization for Large Language Models
    把激活难量化问题转移到权重侧，是 W8A8 路线的关键论文。
  4. AWQ: Activation-aware Weight Quantization for LLM Compression and Acceleration
    激活感知权重量化，工程生态中非常常见。
  5. OmniQuant: Omnidirectionally Calibrated Quantization for Large Language Models
    面向校准和端到端误差控制的 PTQ 路线。
  6. QuIP#: Even Better LLM Quantization with Hadamard Incoherence and Lattice Codebooks
    旋转、码本和低比特权重量化的重要参考。

6.3 QLoRA、低资源微调与量化训练

  1. QLoRA: Efficient Finetuning of Quantized LLMs
    量化底座 + LoRA 微调的核心论文。
  2. ZeroQuant: Efficient and Affordable Post-Training Quantization for Large-Scale Transformers
    结合分层量化和系统部署的早期代表。
  3. FP8-LM: Training FP8 Large Language Models
    FP8 训练 LLM 的早期系统路线，重点是梯度、优化器状态和缩放策略。
  4. DeepSeek-V3 Technical Report
    671B MoE、MLA、MTP、FP8 mixed precision、DualPipe 和 SFT/RL 后训练的完整系统报告；站内专题见 DeepSeek-V3 讲解。
  5. COAT: Compressing Optimizer States and Activation for Memory-Efficient FP8 Training
    重点关注 optimizer states 和 activation，适合作为“低比特训练不只是压权重”的参考。
  6. Scaling FP8 Training to Trillion-Token LLMs
    讨论大规模 FP8 训练稳定性，尤其是 SwiGLU outlier 和长训练后期风险。
  7. To FP8 and Back Again: Quantifying Reduced Precision Effects on LLM Training Stability
    低精度训练稳定性评估参考，提醒不要只看短跑 loss。
  8. μnit Scaling: Simple and Scalable FP8 LLM Training
    静态缩放和参数化改造路线，适合关注“降低动态 scale 管理复杂度”的读者。
  9. Recipes for Pre-training LLMs with MXFP8
    MXFP8 预训练配方，适合和传统 FP8 训练对比。

6.4 FP4、MXFP4、NVFP4 与前沿低比特训练

  1. Optimizing Large Language Model Training Using FP4 Quantization
    FP4 训练框架代表，重点是可微量化估计、outlier clamp 与 mixed precision。
  2. Training LLMs with MXFP4
    MXFP4 训练路线，适合对比 Microscaling 和随机 Hadamard 变换如何处理 outlier。
  3. Quartet: Native FP4 Training Can Be Optimal for Large Language Models
    面向原生 FP4 硬件和 kernel 的训练路线，强调 scaling law、梯度无偏和 Blackwell 上的实现。
  4. Pretraining Large Language Models with NVFP4
    NVFP4 预训练代表，关注 1x16 / 16 元素微块、FP8 scale 和长 token 训练稳定性。
  5. Bridging the Gap Between Promise and Performance for Microscaling FP4 Quantization
    对 MXFP4 / NVFP4 PTQ 和硬件 kernel 的系统分析，提醒 FP4 格式需要方法与 kernel 配套。
  6. Four Over Six: More Accurate NVFP4 Quantization with Adaptive Block Scaling
    4/6 adaptive block scaling，适合理解 NVFP4 中“缩到 6 不一定最优”的问题。
  7. Quartet II: Accurate LLM Pre-Training in NVFP4 by Improved Unbiased Gradient Estimation
    NVFP4 预训练的后续路线，重点是更好的无偏梯度估计。

低比特训练的核心阅读线

如果你要研究 FP8/FP4 训练，不要只按 bit 数排序。更好的阅读顺序是：先看 FP8 Formats 和 Microscaling 理解数制，再看 FP8-LM / COAT / Scaling FP8 理解 activation 与 optimizer 状态，再看 MXFP8 / MXFP4 / NVFP4 / Quartet 理解 4-bit 训练为什么必须同时改数制、scale、rounding、kernel 和稳定性评测。

6.5 量化运行时、ONNX 与可视化工具

  1. ONNX Runtime Quantization Documentation
    ONNX 量化实践入口，适合模型导出、校准、静态/动态量化和部署链路。
  2. ONNX Runtime GitHub
    官方实现与 issue 入口。
  3. Netron
    模型图可视化工具，适合检查 ONNX 节点、权重量化节点和算子路径。
  4. Qualcomm AI Hub Documentation
    移动端和 Qualcomm 设备部署入口。
  5. Qualcomm AI Engine Direct SDK / QNN
    QNN 路线入口，QNN_DLC 相关部署常需要结合 SDK 文档、转换工具和目标芯片支持矩阵看。

7. MTP、投机解码与推理加速

对应站内章节：MTP 与投机解码、缓存、路由与投机执行。

7.1 MTP 与多 token 预测

  1. Blockwise Parallel Decoding for Deep Autoregressive Models
    可以看作多 token 并行预测和验证的早期思想源头。
  2. ProphetNet: Predicting Future N-gram for Sequence-to-Sequence Pre-training
    未来 n-gram 预测目标，适合理解“让模型提前规划未来 token”的训练动机。
  3. Better & Faster Large Language Models via Multi-token Prediction
    Meta MTP 路线：共享 trunk + 多个 future-token heads，强调 sample efficiency 和自投机推理收益。
  4. DeepSeek-V3 Technical Report
    DeepSeek-V3 把 MTP 写进训练目标，同时采用 MoE、MLA 和高效训练系统，是工程化 MTP 的重要参考。
  5. DeepSeek-V3 GitHub
    查看模型发布、配置和实现细节。
  6. Multi-Token Prediction Needs Registers
    MuToR 用 register token 做多未来监督，优点是尽量减少架构侵入。
  7. L-MTP: Leap Multi-Token Prediction Beyond Adjacent Context for Large Language Models
    跨步 MTP 路线，重点是非相邻未来 token、look-backward 和推理步长压缩。

7.2 标准投机解码与自投机解码

  1. Fast Inference from Transformers via Speculative Decoding
    经典投机解码入口：小 draft model 提案，大 target model 并行验证，并保持输出分布一致。
  2. Draft & Verify: Lossless Large Language Model Acceleration via Self-Speculative Decoding
    自投机解码路线，不依赖额外小模型，而是利用模型内部路径做 draft。
  3. LayerSkip: Enabling Early Exit Inference and Self-Speculative Decoding
    Meta 的 early exit + self-speculative 路线，和 Logit Lens、中间层可解码性关系紧密。
  4. SpecExec: Massively Parallel Speculative Decoding for Interactive LLM Inference on Consumer Devices
    关注消费级设备和 offloading 场景下的大规模草稿树验证。
  5. OPT-Tree: Speculative Decoding with Adaptive Draft Tree Structure
    自适应 draft tree 路线，适合和 EAGLE-2 动态树对照。

7.3 EAGLE 系列与特征级 draft

  1. EAGLE: Speculative Sampling Requires Rethinking Feature Uncertainty
    从 token draft 转向 feature draft，重点是特征级自回归和不确定性处理。
  2. EAGLE-2: Faster Inference of Language Models with Dynamic Draft Trees
    用上下文感知动态草稿树提升接受长度。
  3. EAGLE-3: Scaling up Inference Acceleration of Large Language Models via Training-Time Test
    引入 training-time test 和多层特征融合，解决 feature constraint 带来的数据扩展瓶颈。
  4. EAGLE GitHub
    代码和模型入口。

7.4 量化 + 投机解码

  1. QSpec: Speculative Decoding with Complementary Quantization Schemes
    低精度 W4A4 负责快速草拟，高精度 W4A16 负责验证，是“量化和投机解码耦合”的核心参考。
  2. QSpec GitHub
    复现入口。
  3. An Introduction to Speculative Decoding for Reducing Latency in AI Inference
    NVIDIA 官方博客，适合工程入门和向非算法同学解释 draft/verify 机制。
  4. TorchSpec
    PyTorch 原生 speculative decoding 训练框架，适合追踪工程实现。

MTP 与投机解码的阅读重点

MTP 是训练目标或模型结构；speculative decoding 是推理算法。二者可以互相增强，但不能互相替代。阅读时要同时盯三类指标：主模型质量、多步预测接受率、端到端 latency / throughput。只看 future-token accuracy 或平均 speedup 都容易误判。

8.3 MoE、路由与大规模稀疏训练

  6. Qwen3 Technical Report
    Qwen3 同时发布 dense 与 MoE 模型，MoE 采用 128 total experts / 8 activated experts，并用 global-batch load balancing loss；站内专题见 Qwen3 讲解。
  7. Kimi K2: Open Agentic Intelligence
    Kimi K2 采用 1.04T total / 32.6B activated 的 ultra-sparse MoE，使用 384 total experts / 8 active experts，并通过 sparsity scaling law 选择 sparsity 48；站内专题见 Kimi K2 讲解。
