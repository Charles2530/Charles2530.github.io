基础知识：符号与最小数学地图

这页是基础知识模块的随手查表。第一次读 AI 教程时，真正卡人的往往不是公式本身，而是符号没有说明：xxx 是输入还是图像，WWW 是权重还是宽度，HHH 是图像高度还是预测 horizon。

读法定位

这页先回答“符号与最小数学地图”在「基础知识」里的位置：它解决什么局部问题，依赖哪些前置，最后会影响哪类工程或研究判断。
前置：先看本页要补哪一个最小概念；公式或术语卡住时回到术语表，不需要一次吃完整个数学体系。 必要时先回 基础知识入口 或 术语表。
主线关系：把符号、张量、优化、评测和运行时这些前置打稳，后面的扩散、VLM/VLA、训练与系统页才不会断层。

初学者先抓住

看到公式先不要急着推导。按四步读：谁是输入，谁是输出，条件是什么，模型在优化什么。只要这四件事能说清，大多数公式都会从“看不懂的数学”变成“数据流的压缩写法”。

Shape 字母：先知道张量有多大

Shape 是模型模块之间的接口契约。本站会尽量沿用下面的写法。

符号 读法 常见含义 小例子
BBB batch size 一次处理多少样本 B=8 表示 8 条样本一起算
LLL sequence length token 数或序列长度 文本长度、视觉 token 数
DDD hidden dimension 每个 token 的向量维度 D=4096
CCC channel 图像通道或特征通道 RGB 图像里 C=3
HimgH_{\text{img}}Himg​ image height 图像高度 224 像素
WimgW_{\text{img}}Wimg​ image width 图像宽度 224 像素
PPP patch size 图像 patch 边长 ViT 常见 P=16
NNN token 或样本数量 具体含义看上下文 NNN 个 patch、NNN 条数据
TTT time length 时间步或总序列长度 16 帧视频、64 步轨迹

一个文本 batch 常写成：

x∈RB×L×Dx \in \mathbb{R}^{B \times L \times D} x∈RB×L×D

读作：xxx 是一个三维张量，有 BBB 条样本，每条样本有 LLL 个 token，每个 token 是 DDD 维向量。

同一个字母在不同页面可能换意思

HHH 在图像里常是 height，在世界模型里常是 horizon，在 attention 里也可能是 head 数。教程会尽量写成 HimgH_{\text{img}}Himg​、HhorH_{\text{hor}}Hhor​、HheadsH_{\text{heads}}Hheads​ 来避免混淆。

模型和参数：谁在被训练

符号 读法 含义
fθf_\thetafθ​ f theta 参数为 θ\thetaθ 的模型函数
θ\thetaθ theta 模型参数的集合
WWW weight matrix 权重矩阵
bbb bias 偏置
hhh hidden state 中间隐藏表示
zzz latent state 模型内部压缩状态
y^\hat yy^​ y hat 模型预测值
yyy y 真实标签或目标输出

最常见的线性层公式是：

y=xW+by = xW + b y=xW+b

逐项读：

部分 含义
xxx 输入向量或输入张量
WWW 可训练权重，决定怎么重新组合输入特征
bbb 偏置，让输出可以整体平移
yyy 输出表示

如果写成 y^=fθ(x)\hat y=f_\theta(x)y^​=fθ​(x)，意思就是“模型用参数 θ\thetaθ 处理输入 xxx，得到预测 y^\hat yy^​”。

概率符号：模型在给可能性打分

符号 读法 含义
p(x)p(x)p(x) probability of x xxx 出现的概率或密度
pθ(x)p_\theta(x)pθ​(x) model distribution 参数为 θ\thetaθ 的模型分布
p(y∣x)p(y\mid x)p(y∣x) y given x 给定 xxx 时 yyy 的条件概率
qϕ(z∣x)q_\phi(z\mid x)qϕ​(z∣x) q phi 参数为 ϕ\phiϕ 的近似后验或推断模型
log⁡p(x)\log p(x)logp(x) log probability 对数概率，训练里更容易相加
N(x;μ,Σ)\mathcal{N}(x;\mu,\Sigma)N(x;μ,Σ) Gaussian density 在变量 xxx 上取值或采样的高斯分布；μ\muμ 是均值，Σ\SigmaΣ 是协方差

注意两种常见写法的区别：N(x;μ,Σ)\mathcal{N}(x;\mu,\Sigma)N(x;μ,Σ) 把“变量、均值、协方差”三个位置都写出来；z∼N(0,I)z\sim\mathcal{N}(0,I)z∼N(0,I) 是采样简写，左边的 zzz 已经说明变量，所以括号里只剩“均值 0、协方差 III”。

条件概率里的竖线 ∣\mid∣ 读作“given”。例如：

pθ(y∣x)p_\theta(y \mid x) pθ​(y∣x)

读作：给定输入 xxx，模型输出 yyy 的概率。它不保证 yyy 一定正确，只表示模型认为哪个输出更可能。

在 VLA 或世界模型里常见：

pθ(zt+1∣zt,at)p_\theta(z_{t+1}\mid z_t,a_t) pθ​(zt+1​∣zt​,at​)

读作：给定当前 latent state ztz_tzt​ 和动作 ata_tat​，模型预测下一步 latent state zt+1z_{t+1}zt+1​ 的分布。

Loss、梯度和优化：模型怎么变好

符号 读法 含义
L\mathcal{L}L loss 损失函数，衡量预测和目标的差距
ℓ(y^,y)\ell(\hat y,y)ℓ(y^​,y) per-example loss 单个样本的损失
∇θL\nabla_\theta \mathcal{L}∇θ​L gradient w.r.t. theta loss 对参数 θ\thetaθ 的梯度
η\etaη learning rate 学习率，每次更新走多大一步
←\leftarrow← update to 更新赋值

最小训练更新可以写成：

θ←θ−η∇θL\theta \leftarrow \theta - \eta \nabla_\theta \mathcal{L} θ←θ−η∇θ​L

部分 含义
θ\thetaθ 当前模型参数
∇θL\nabla_\theta \mathcal{L}∇θ​L 哪个方向会让 loss 变大
−∇θL-\nabla_\theta \mathcal{L}−∇θ​L 往相反方向走，通常能让 loss 变小
η\etaη 步长，太大可能发散，太小会很慢

求和、期望和范数：把很多样本合起来

符号 读法 含义
∑i\sum_i∑i​ sum over i 对很多项求和
∏i\prod_i∏i​ product over i 对很多项连乘
E[⋅]\mathbb{E}[\cdot]E[⋅] expectation 对随机样本取平均意义上的值
∥x∥2\|x\|_2∥x∥2​ L2 norm 向量长度
∥x−y∥22\|x-y\|_2^2∥x−y∥22​ squared L2 distance MSE 常见形式
KL⁡(q∥p)\operatorname{KL}(q\|p)KL(q∥p) KL divergence 两个分布差多少

例如行为克隆损失：

LBC=−∑(o,l,a)∈Dlog⁡πθ(a∣o,l)\mathcal{L}_{\text{BC}} =-\sum_{(o,l,a)\in\mathcal{D}}\log \pi_\theta(a\mid o,l) LBC​=−(o,l,a)∈D∑​logπθ​(a∣o,l)

可以拆成一句话：训练集 D\mathcal{D}D 里每条样本都有观测 ooo、语言 lll、专家动作 aaa；我们让策略 πθ\pi_\thetaπθ​ 更倾向于在同样输入下输出专家动作。

时间下标：模型在第几步看见什么

符号 含义
ttt 当前时间步
t+1t+1t+1 下一步
oto_tot​ 第 ttt 步观测
ata_tat​ 第 ttt 步动作
o≤to_{\le t}o≤t​ 从过去到当前的所有观测
at:t+H−1a_{t:t+H-1}at:t+H−1​ 从 ttt 开始的一段动作序列
HhorH_{\text{hor}}Hhor​ 预测 horizon，往未来看多少步

例如：

πθ(at∣o≤t,l)\pi_\theta(a_t\mid o_{\le t}, l) πθ​(at​∣o≤t​,l)

读作：策略根据到目前为止的观测 o≤to_{\le t}o≤t​ 和语言指令 lll，输出当前动作 ata_tat​ 的概率或动作值。

复杂度符号：为什么有的模型跑不动

写法 直觉
O(L)O(L)O(L) 序列长度翻倍，成本大约翻倍
O(L2)O(L^2)O(L2) 序列长度翻倍，成本大约变四倍
O(BLD)O(BLD)O(BLD) batch、长度、维度都会线性增加成本
B×L×D×bytesB\times L\times D\times bytesB×L×D×bytes 一个 hidden tensor 的大致显存

Attention 最常见的成本提醒是：

score matrix size∝L2\text{score matrix size} \propto L^2 score matrix size∝L2

也就是说，token 数 LLL 一多，注意力分数矩阵会平方放大。多相机视频、长上下文和多轮对话都容易在这里变贵。

读公式的固定四问

以后在基础页或论文页看到公式，可以按下面四问走：

  1. 输入是什么：xxx、oto_tot​、ztz_tzt​、ata_tat​ 分别来自哪里？
  2. 输出是什么：预测 token、动作、latent、reward，还是概率？
  3. 条件是什么：竖线 ∣\mid∣ 后面的变量是不是都在模型可见范围内？
  4. 优化什么：loss 是让输出更像标签，还是让分布、风险、奖励或成本更好？

如果这四问答不清，先回到本页查符号，再继续读具体模型。
